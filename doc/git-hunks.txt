`GIT-HUNKS.NVIM`                                    *git-hunks-git-hunks.nvim*


A minimal plugin to view, navigate, and reset git hunks. Also includes a diff
view for comparing any two git file locations.


------------------------------------------------------------------------------
FEATURES                                                  *git-hunks-features*


- 2 source files (~700 LOC), 1 test file (~700 LOC), no runtime dependencies
- Async diff computation via coroutines (no UI freezing)
- Signs update on every edit with debouncing (300ms)
- Watches `.git/index` and `.git/HEAD` for external changes (e.g. `git
  checkout`, `git stash`, `git reset`)
- Navigate to next/previous hunk with wrapping
- Reset a single hunk, a visual selection of hunks, or the entire file

------------------------------------------------------------------------------
EXAMPLE CONFIG                                      *git-hunks-example-config*


>lua
    vim.keymap.set("n", "]h", "<Plug>GitHunksNextHunk")
    vim.keymap.set("n", "[h", "<Plug>GitHunksPrevHunk")
    
    vim.keymap.set("n", "gh", "<Plug>GitHunksResetHunk")
    vim.keymap.set("v", "gh", "<Plug>GitHunksResetHunk")
    vim.keymap.set("n", "gH", "<Plug>GitHunksResetFile")
<

------------------------------------------------------------------------------
PLUG REMAPS                                            *git-hunks-plug-remaps*



                                                                              
`<PLUG>GITHUNKSNEXTHUNK`                    *git-hunks-<plug>githunksnexthunk*

Navigate to the next hunk. Wraps to the first hunk if none remain.


                                                                              
`<PLUG>GITHUNKSPREVHUNK`                    *git-hunks-<plug>githunksprevhunk*

Navigate to the previous hunk. Wraps to the last hunk if none remain.


                                                                              
`<PLUG>GITHUNKSRESETHUNK`                  *git-hunks-<plug>githunksresethunk*

- In normal mode: reset the hunk on the current line
- In visual mode: reset all hunks that overlap with the visual selection

                                                                              
`<PLUG>GITHUNKSRESETFILE`                  *git-hunks-<plug>githunksresetfile*

Reset the entire file to the index version.

| ---------------- | ------------ | -------------- |
| `DiffSignDelete` | `DiffDelete` | Deleted lines  |

AUTOCOMMAND EVENTS                              *git-hunks-autocommand-events*



                                                                              
`USER GITINDEXCHANGED`                        *git-hunks-user-gitindexchanged*

Fired when `.git/index` changes on disk (e.g. `git add`, `git checkout`, `git
stash`, `git reset`).


                                                                              
`USER GITHEADCHANGED`                          *git-hunks-user-githeadchanged*

Fired when `.git/HEAD` changes on disk (e.g. `git checkout <branch>`, `git
reset --hard`).
